## Исправленные проблемы текущей реализации

Все перечисленные проблемы были внесены в ходе этой задачи и устранены до завершения.

| Приоритет | Место исправления | Доказательство и результат |
|---|---|---|
| Высокий | `src/local_store.cpp:20,99` | Аккаунт без псевдонима получал `NOT NULL constraint failed`. Пустые QString преобразованы в непустой по null-семантике пустой TEXT; внешний сценарий добавления и повторного открытия прошёл. |
| Высокий | `src/api_client.cpp:107` | При несовпадении тега разобранный результат мог сохраниться рядом с ошибкой. Catch теперь сбрасывает и типизированные данные, и тело ответа. |
| Средний | `qml/AccountsManager/ActivityStatus.qml:22` | Визуальная проверка обнаружила обращение к неверному ключу карты. Восстановлен `activity.status`; текст проверен в визуальном дереве и на скриншоте. |
| Средний | `qml/AccountsManager/AccountEditor.qml:12` и другие диалоги | Программный рендеринг не рисовал фон со стандартной Material elevation. Отключена необязательная тень; фон повторно проверен визуально. |
| Средний | `AccountEditor.qml`, `AccountsPage.qml`, `SettingsDialog.qml` | Формы больше не закрываются/не очищаются до подтверждения SQLite. При отказе записи черновик сохраняется. |
| Средний | `src/accounts_model.cpp`, `src/domain.cpp` | Будущий план не выделяется как просроченный; возврат в ЛВК не вычисляется по устаревшему профилю; неизвестные/будущие состояния войны не требуют атаки. |

## Реально выполненные проверки

- Debug и Release: CMake, Clang 23.1.5, `-std=c++26`,
  `-Wall -Wextra -Wpedantic -Werror`, компиляция и линковка.
- Внешние проверки в `/tmp`: теги, optional/null/overflow, дубликаты атак,
  фазы КВ, приоритет раундов ЛВК, сезонный и раундовый состав, Ranked без
  недоказанного счётчика, соответствие идентификатора ресурса.
- SQLite/модель: добавление, дубликаты, редактирование с апострофом, отмена плана,
  порядок, удаление, перезапуск, сохранение периода, откат транзакции,
  отказ от изменения более новой и повреждённой базы.
- ASan/UBSan для предметной логики и SQLite/модели; поиск утечек отключён.
- Offscreen GUI: непустая панель, подпись статуса, вкладка аккаунтов,
  диалоги редактирования/настроек/удаления, окно 540×480; скриншоты просмотрены.
- `git diff --check`; пользовательская исходная правка `.gitignore` сохранена.
- `ponytail-review`: просмотр изменённых интерфейсов и вызывающего кода;
  блокирующих замечаний после исправлений не найдено. Новых ORM, backend,
  тестовой инфраструктуры и вспомогательных абстрактных интерфейсов нет.

LeakSanitizer не выполнен: окружение сообщает запрет, связанный с ptrace.
Настройки системы не менялись. Проверки дискового переполнения, отключения питания,
Windows и успешных игровых запросов не выполнялись. Подробности игрового API —
[отдельный контракт](api_contract.md).

Graphify обновляется AST-командой `graphify update .`. Экстрактор не поддерживает
эти QML-файлы и сообщает частичный разбор `Q_PROPERTY` в `accounts_model.hpp`;
документная семантика автоматически этой командой не обновляется. Сам граф не
используется как доказательство корректности реализации.
